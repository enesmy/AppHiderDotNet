# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2025-12-14

### Added
- **Area Censorship**: New feature allowing users to select and censor specific regions of the screen (`Ctrl + Shift + 3` or via Tray Icon).
- **Liquid Glass Theme**: Complete UI overhaul with a modern, semi-transparent, glassmorphism design.
- **Overlay Button**: A floating button for quick access to hide/show functions and main window.
- **Censor Overlay Window**: Dedicated window for rendering the blur effect on selected areas.
- **Area Selection Window**: Interactive window for selecting screen regions to censor.

### Changed
- **App Icon**: Updated to a new, more modern lock icon.
- **UI Improvements**: Enhanced visual feedback and animations across the application.
- **Blur Overlay**: Improved z-order handling to ensure the blur effect stays correctly positioned.

### Fixed
- **Blur Overlay Z-Order**: Resolved issues where the blur overlay would not stay on top of the target window or would interfere with other windows.
